# 콘텐츠 제작 가이드

- DAY 번호는 세 자리로 표기합니다. 예: DAY 007, 라우트는 `/days/day-007`입니다. 번호는 재사용하지 않으며 테스트용 DAY 000은 공식 작품 번호와 구분합니다.
- `creator`는 `언니`, `동생`, `공동` 중 하나로 기록합니다.
- 릴스·쇼츠의 제목, DAY 번호, 작품 제목을 동일하게 유지하고 영상 설명에는 갤러리 또는 작품 URL을 넣습니다.
- `draft`는 갤러리에서 Coming Soon으로 보이며 클릭 링크를 만들지 않습니다. `published`만 갤러리에서 이동합니다. 상태는 보안·접근 제어가 아닙니다.
- 썸네일은 `public/thumbnails/day-XXX.*`에 두고 `thumbnail` 필드에 기록합니다. 16:10 비율과 식별 가능한 강한 대비를 권장하며, 외부 자산은 사용 권한을 확인합니다.
